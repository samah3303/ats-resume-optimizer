# 🏛️ Paniund — Institutional Career & ATS Operating System

Paniund is a personal career operating system designed to automate resume optimization, job discovery, and application tracking with the conservative elegance and precision of the **VaultLine** design system.

---

## ⚡ Core Architecture & Workflow

1. **Zero-Friction Resume Ingestion**
   - Drag-and-drop any PDF, DOCX, or TXT resume on the landing page.
   - Auto-extracts contact email, location, skills, work experience, and education.
   - Automatically sets up account with a single password prompt.

2. **Institutional ATS Analysis & Scoring**
   - Real-time ATS compatibility scoring (0–100) with detailed dimensional breakdown:
     - **Keywords Density**
     - **Structural Formatting**
     - **Action Verbs & Impact**
     - **Metrics & Quantification**
   - Actionable recommendations generated by LLM analysis.

3. **Opportunity Pipeline & URL Autofill**
   - Paste any job URL from LinkedIn, Indeed, NaukriGulf, or Glassdoor to auto-extract position details, title, company, requirements, and compensation.
   - Direct gateways to search external marketplaces.

4. **AI Generation Suite**
   - **Tailored Cover Letters**: Job-specific letters highlighting matching career accomplishments.
   - **ATS Resume Modifications**: Side-by-side diff view of original bullets vs suggested optimized replacements with keyword additions.
   - **Follow-up Emails**: Polite follow-up drafts for post-application, post-interview, or status checks.
   - **LinkedIn Outreach Messages**: Tailored connection requests (<300 characters), recruiter InMails, or informational chats.

5. **Application Kanban Tracker**
   - Drag-and-drop style stage tracking across 7 stages:
     - `Wishlist` → `Applied` → `Phone Screen` → `Interview` → `Offer` → `Accepted` → `Rejected`
   - Interview scheduler, recruiter contacts, and preparation notes log.

---

## 🎨 VaultLine Design System

- **Primary Navy** (`#1E3A5F`): Headers, primary actions, navigation
- **Secondary Gold** (`#C49A2A`): Metric highlights and verified badges
- **Tertiary Ivory** (`#FFFDF7`): Page background
- **Typography**:
  - Headlines & Subheads: `DM Serif Display`
  - Body, Badges & Labels: `Inter`
  - Tabular Numbers & Timestamps: `IBM Plex Mono`
- **Dynamic Density**:
  - One-click toggle between **Dense** (compact 14px cards, 32px controls, 10px gaps) and **Relaxed** (24px cards, 40px controls, 16px gaps).

## 🚀 Getting Started

### Prerequisites

- Node.js 20+
- PostgreSQL (Neon Serverless recommended)

### Setup

```bash
# Install dependencies
npm install

# Push database schema
npx prisma db push

# Start local dev server
npm run dev
```

Server runs locally at `http://localhost:3000`.
